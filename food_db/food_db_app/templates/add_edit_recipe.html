Linked Recipes

Search here to link related recipes. There are two types of relationships: Full/Component and Variant/Base. The "parent" recipe (either the Full or the Variant, depending on the relationship type) is composed of, and therefore displays, all the ingredients and steps of the "child" recipes (Component or Base). The parent does not need its own ingredients or steps, but you can optionally add some (like for topping and/or assembly instructions). Parent-specific ingredients/steps will always be shown last, after the children.

Full/Component relationships are used in cases like cakes, where the sponge and frosting are separate Component recipes and the complete cake is the Full recipe.

Variant/Base relationships are when you have multiple different versions of a food that are mutually exclusive. For example, you might have a Base recipe for a type of bread, and then have Variant recipes for sweet and savory versions.

Indicate the relationship each recipe has to this one using the dropdown menu. Use the arrows to change the display order of your child recipes. If you are establishing this recipe as a child and a different one as a parent, you can change the display order of this recipe from the parent's page.

Recipe

You can format the text of your recipe steps using Markdown syntax. You can google the full set of rules, but here are some of the most common tricks:

• **Double asterisks** make text bold
• *Single asterisks* or _underscores_ make it italic.
• Use hyphens or asterisks to create bullet points
• Make headings by starting a line with 1-4 hash symbols (#), like this:

# This is a large header
#### This is a small one
This is the normal text

There is also a custom syntax that you can use to create tooltips over your text that link back to ingredients. There are long and short forms of the syntax:

This short form is the easiest and can be used when you're fine with the visible hyperlink text being the same as the food name:
[ingredient food name]

This medium form is the same as above, but lets you set a different visible text than the food's name:
[visible hyperlink text](!ingredient food name)

This longest form is only necessary when the same food is used in multiple different ingredient categories and you need to specify one:
[visible hyperlink text](!ingredient food name;ingredient category name)
